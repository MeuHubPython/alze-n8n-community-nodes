#### [2.0.0](https://github.com/MeuHubPython/alze-n8n-community-nodes/compare/1.7.0...2.0.0)

**Breaking changes**

- Removed the Won Reason resource: the API no longer has `/win-reasons`.
- Removed User › Get, Webhook › Update Partial and Activity › Update Partial: the API has no such routes (they already failed with 404). A workflow still saved with them now fails with "no longer supported".
- Order Direction defaults to the API order. Get Many without an explicit direction no longer sends `desc`: activities come by `due_date` asc, pipelines by `position` asc, loss reasons by `name` asc.
- Deal › Win only sends Value when it is not 0 (0 used to zero the deal value). Deal › Add Item only sends Price when it is not 0 (0 used to override the catalog price).
- Contact phone types are `mobile`, `fixed`, `whatsapp`, `work`, `other`; saved `home`/`phone` are sent as `fixed`.
- Custom Field: `boolean` type and `contacts` entity removed (the API never accepted them); Entity is no longer editable on update.
- Empty list filters are now sent to the API instead of being dropped (`phone_match=` returns nobody).
